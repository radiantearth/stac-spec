# STAC specification

This is an HTML rendering of the [SpatioTemporal Asset Catalog (STAC) specification](https://stacspec.org).
The specification consists of three parts:

- [Item](./item-spec/item-spec.md)
- [Collection](./collection-spec/collection-spec.md)
- [Catalog](./catalog-spec/catalog-spec.md)

The source for these documents is the [stac-spec repository](https://github.com/radiantearth/stac-spec/).
Use [issues](https://github.com/radiantearth/stac-spec/issues) for any bugs or other problems, and use [discussions](https://github.com/radiantearth/stac-spec/discussions) for questions or other conversations.

The STAC API specification, which describes how STAC can be served and searched, lives in its own [repository](https://github.com/radiantearth/stac-api-spec) and is not included in these pages.
